# Дед Мороз против дронов

Небольшая браузерная аркада на TypeScript, Phaser и Vite. Дед Мороз уворачивается от дронов, которые прилетают с четырёх сторон. Подарки автоматически летят в ближайшего дрона.

## Управление и цель

- **WASD** — движение.
- Собирайте монеты, выпавшие из сбитых дронов.
- Каждые 5 монет повышают скорострельность.
- У Деда Мороза 5 единиц здоровья. При столкновении с дроном теряется 1 единица.
- После поражения нажмите **R** или кнопку «Играть снова».
- Результат — число сбитых дронов и время полёта.

## Запуск на компьютере

Нужен Node.js версии 20.19 или новее. В PowerShell на Windows используйте `npm.cmd`, если запуск `npm.ps1` заблокирован.

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, который напечатает Vite, обычно `http://localhost:5173/`.

## Проверка

```powershell
npm.cmd run typecheck
npm.cmd run build
```

## Состояние проекта

Это локальный игровой прототип. Публичная ссылка и проверка другим игроком пока не сделаны. Графика составлена из простых фигур; звук, другие типы врагов и ручное прицеливание пока не реализованы.
