# Дед Мороз против дронов

Небольшая браузерная аркада на TypeScript, Phaser и Vite. Дед Мороз летает по большой карте, уворачивается от дронов и автоматически бросает подарки в ближайшего врага. Камера следует за игроком; за пределы карты улететь нельзя.

## Управление и цель

- **WASD** — движение.
- Собирайте монеты, выпавшие из сбитых дронов.
- Каждые 5 монет открывают меню выбора улучшения. Пока доступна только скорострельность: выберите её мышью или клавишей **1**. Пока меню открыто, игра остановлена.
- У Деда Мороза 5 единиц здоровья. При столкновении с дроном теряется 1 единица.
- После поражения нажмите **R** или кнопку «Играть снова».
- За каждую секунду выживания даётся 1 очко, за каждого сбитого дрона — 10 очков. На экране видны таймер, счёт и число сбитых дронов.

## Запуск на компьютере

Нужен Node.js версии 20.19 или новее. В PowerShell на Windows используйте `npm.cmd`, если запуск `npm.ps1` заблокирован.

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, который напечатает Vite, обычно `http://localhost:5173/`.

## Проверка

```powershell
npm.cmd run typecheck
npm.cmd run build
```
